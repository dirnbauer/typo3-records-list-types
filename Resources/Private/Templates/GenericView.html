Generic view: the starting point for a view of your own. Copy this file, register it in Page TSconfig and change the list item. Table/Section frames each table like the list view (heading, table actions, selection bar, pagination, empty state); the Record/* partials render what the list view renders for a record. Variables: - tableData: one entry per table, with - tableName, tableIdentifier, tableLabel, recordCount - records: every record has uid, pid, tableName, title, hidden, displayValues (field => {field, label, type, raw, formatted}), editUrl, contextualEditUrl, iconHtml, controlsHtml, translations, languageTitle, languageFlagIdentifier, workspaceState, permissions - paginator, pagination, paginationUrl, sortingDropdown, sortingModeToggle, actionButtons, filters, emptyState - currentTable: the table of the single-table view, empty otherwise - pageId, searchTerm, viewMode, viewConfig
