Record navigation of the list view (Core's ListNavigation), above and below the records of a single-table view. Arguments: - paginator: DatabasePaginator - pagination: SlidingWindowPagination - paginationUrl: base URL; pointer[table] is appended - tableName: table whose pointer the links change - position: top or bottom, names the two navigation landmarks apart
    • "Page [input] of N" is one translatable sentence; the input replaces the {page} placeholder so the word order is right in every language.
